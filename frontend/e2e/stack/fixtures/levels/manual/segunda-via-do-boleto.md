# Segunda via do boleto

Material sintético para o E2E da stack.

## Como emitir a segunda via do boleto

Para emitir a segunda via do boleto, abra o menu Financeiro, escolha Contas a receber, localize
a fatura pelo número e clique em Segunda via. O boleto novo sai com a data de vencimento
atualizada e pode ser enviado ao cliente por e-mail.
